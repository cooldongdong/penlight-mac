# Penlight

給 **Hawk DR550DL 簡報筆**用的 macOS 原生工具（Apple Silicon）：數位雷射點、聚光燈、放大鏡、滑鼠模式、圓形選單切換、可自訂的按鍵。

> **非官方專案**，與 Hawk（浩客）及原廠軟體無關。不含任何原廠程式或素材；接收器協定是為了互通，自行監聽實機解出來的。
> 原廠軟體只有 Intel 版、未經 Apple 公證，在 macOS 27 之後可能無法執行，這是做這個專案的原因。

## 建置

```sh
./scripts/make-signing-cert.sh   # 只要跑一次：在鑰匙圈建立本機固定簽章
./scripts/build-app.sh           # 產出 build/Penlight.app（arm64）
```

沒有固定簽章的話，每次重新建置 macOS 都會把它當成新 app，權限會掉。

需要兩個權限（系統設定 → 隱私權與安全性），第一次開啟時會有引導視窗：
- **輔助使用**：讀接收器、音量鍵自訂動作、Google 簡報放映、簡報筆專用指標速度
- **螢幕與系統錄音**：放大鏡；辨認 Google 簡報

不需要另外開「輸入監控」：有輔助使用權限的 app 本來就能讀取輸入，macOS 也不會把它列進輸入監控清單。

測試用：`open build/Penlight.app --args --demo magnifier`（不用簡報筆，直接顯示 8 秒）。
除錯紀錄寫在 `~/Library/Logs/Penlight.log`。

## 操作

| 動作 | 效果 |
|---|---|
| 按住模式鍵 | 在游標位置顯示目前的效果（雷射點／聚光燈／放大鏡／滑鼠），放開消失 |
| 按住 ＋ 音量 ＋／− | 切到下一個／上一個模式 |
| 連按兩下、第二下按住，再甩筆 | 圓形選單：上雷射點、右聚光燈、下放大鏡、左滑鼠；放開選定，留在中間則取消 |
| 連按兩下（不按住） | 切到下一個模式（等 0.8 秒確認不是圓形選單） |
| 按住 ＋ 上一頁／下一頁 | 調大小或倍率；短按一格，按住 0.35 秒後連續變化 |
| 音量 ＋／−（短按、長按） | 可在選單指定動作；預設 ＋＝滑鼠點擊、−＝指揮中心 |
| 長按上一頁 | 開始／結束放映（簡報筆自己送快捷鍵；Google 簡報由 app 改送 `⌘Return`） |
| 長按下一頁 | 黑屏（放映中） |

選單列圖示可以設定：模式、切換時是否顯示模式名稱、雷射點顏色、聚光燈暗度、簡報筆指標速度、四個音量鍵位置的動作。

## 接收器協定（2026-11-06～07 實機監聽解出）

接收器 `Wireless Present`，VID `0x2571`、PID `0x4109`，有兩個介面：滑鼠（usage `0x02`）與鍵盤（usage `0x06`）。

**鍵盤介面 vendor input report `4`，第 2 byte**：小於 `0x10` 是旗標，之上是整數代碼。

| 值 | 意義 |
|---|---|
| `0x04` | 模式鍵按住（同時陀螺儀開始移動游標） |
| `0x01` | 按住模式鍵時按住上一頁（放開才清掉；接收器吞掉原本的 Page Up） |
| `0x02` | 按住模式鍵時按住下一頁 |
| `0x08` | 模式鍵連按兩下；若第二下按住，約 0.5 秒後接著送 `0x04` |
| `0xED`／`0xEE` | 按住模式鍵時按音量 ＋／−（系統音量不會變） |
| `0x80` | 心跳，約每秒一次 |

- 放開時送 `0x00`，但偶爾手還按著就先送 `0x00`；所以「放開」要等筆的滑鼠訊號也停下來才算。
- 雷射鍵只發實體綠光，不傳任何訊號。
- 翻頁、長按上一頁、長按下一頁（`B`）、音量鍵是一般鍵盤／consumer 訊號（report `1`／`2`）。
- 長按上一頁送 `Shift+F5`（PowerPoint）接著 `⌘⌥P`（Keynote）；**接收器自己記放映狀態**，下一次長按改送 `Esc`。
- **滑鼠介面可以獨佔（seize），鍵盤介面不行**（`0xe00002c1`，一般 app 不准獨佔鍵盤類裝置）。所以簡報筆的按鍵一定會進系統，要靠 event tap 辨認：
  - 一般按鍵帶 keyboard type `40`（Mac 內建鍵盤是 `106`）。
  - 音量鍵沒有 keyboard type，但接收器的 HID report 比系統事件早 1～13 毫秒到，所以「60 毫秒內簡報筆送過按鍵」就算是簡報筆的。
- **計時器封包**（從原廠程式反組譯得出）：output report `3`，8 bytes，用 `IOHIDDeviceSetReport` 送到鍵盤介面。
  計時中每 2 秒送一次 `03 01 02 03 04 <剩餘秒數低位> <剩餘秒數高位> 01`，結束送 `03 01 02 03 04 00 00 00`。
  接收器都會接受（回傳 0），但 **DR550DL 實測沒有震動**；原廠程式有 `isAlarmEnable` 之類的開關，震動應該只有部分型號支援。
  只測了 10 秒倒數，沒有排除「只在特定剩餘時間才震」的可能。
