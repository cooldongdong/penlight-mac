# Hawk Presenter（自製版）

Hawk DR550DL 簡報筆的 macOS 原生工具，取代原廠只有 Intel 版、未公證的 `Hawk Presenter-CNF.app`。

## 建置

```sh
./scripts/build-app.sh   # 產出 build/Hawk Presenter.app（arm64，用本機固定簽章）
```

第一次建置前先跑一次 `./scripts/make-signing-cert.sh`，建立固定的本機簽章；否則每次重新建置，macOS 都會把它當成新 app，權限會掉。

需要兩個權限（系統設定 → 隱私權與安全性）：
- **輸入監控**：讀接收器
- **螢幕與系統錄音**：放大鏡

測試用：`open "build/Hawk Presenter.app" --args --demo magnifier`（不用簡報筆，直接顯示 8 秒）。

## 操作

| 動作 | 效果 |
|---|---|
| 連按兩下模式鍵 | 切換 雷射點 → 聚光燈 → 放大鏡 |
| 按住模式鍵 | 在游標位置顯示目前的效果，放開消失 |
| 按住模式鍵 ＋ 上一頁／下一頁 | 雷射點／聚光燈變大變小；放大鏡調倍率（1.5～5 倍） |

## 接收器協定（2026-11-06 實機監聽解出）

接收器 `Wireless Present`，VID `0x2571`、PID `0x4109`。鍵盤介面的 vendor input report `4`，第 2 byte 是旗標：

| 值 | 意義 |
|---|---|
| `0x04` | 模式鍵按住（同時陀螺儀開始移動游標） |
| `0x01` | 按住模式鍵時按上一頁（接收器吞掉原本的 Page Up） |
| `0x02` | 按住模式鍵時按下一頁 |
| `0x08` | 模式鍵連按兩下 |
| `0x80` | 心跳，約每秒一次 |

- 放開時送 `0x00`，但偶爾手還按著就先送 `0x00`；所以「放開」要等筆的滑鼠訊號也停下來才算。
- 雷射鍵只發實體綠光，不傳任何訊號。
- 翻頁、長按上一頁（`Shift+F5` 與 `⌘⌥P`）、長按下一頁（`B`）、音量鍵都是一般鍵盤訊號，系統自己處理。
- 尚未解出：vendor output report `3`（7 bytes），原廠用來讓接收器震動／發聲提醒計時。
